========== 密閉空間監測系統 — 操作說明 ==========

【腳本位置】
三個腳本都放在桌面（~/桌面/）

==================================================
步驟一：禁用系統自動更新（只需做一次）
==================================================

打開終端，執行：

    cd ~/桌面
    sudo bash disable_linux_updates.sh

完成後重啟：

    sudo reboot

注意：這個需要 sudo，做一次就永久生效，不需要重複執行。

==================================================
步驟二：安裝開機自啟動（只需做一次）
==================================================

打開終端，執行：

    cd ~/桌面
    bash install_confined_autostart.sh

注意：
- 不要加 sudo，否則路徑會出錯
- 腳本內部需要 sudo 的地方會自動處理

==================================================
步驟三：手動啟動監測系統（每次需要時）
==================================================

打開終端，執行：

    cd ~/桌面
    bash start_confined_space.sh

注意：不要加 sudo

==================================================
完成步驟二後，重啟電腦可測試是否自動啟動：

    sudo reboot

==================================================
常見問題
==================================================

Q: 執行腳本提示「找不到命令」？
A: 要加 bash 前綴，例如：bash start_confined_space.sh
   或先賦予權限：chmod +x *.sh，再用 ./腳本名.sh

Q: 提示「找不到程序本體」？
A: 不要用 sudo 執行 install / start 腳本，sudo 會讓路徑出錯

Q: packagekit masked 報錯？
A: 可以忽略，不影響功能
